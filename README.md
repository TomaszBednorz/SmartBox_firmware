# SmartBox_firmware

PROJECT IN PROGRESS

The main purpose of this project is to create an IoT device with simple functionalities, such as a pedometer, an alarm clock, and more. Additionally, all information will be logged via Bluetooth Low Energy and used in a mobile application, which will be developed later. The project is being developed using the Nordic Thingy:53 IoT prototyping platform.
